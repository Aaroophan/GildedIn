# Tenancy trust boundaries (Issue 5)

The tenant resolver owns a **stable portfolio ID**, not an OAuth email, mutable handle or guessed subdomain. Claims form one globally unique namespace, including old aliases. `portfolios.slug` is a mirror; a slug claim is never an authorization grant. `renameOperations` is a replay journal; use the same official driver session for claim updates, portfolio CAS, journal and audit or fail *before* any writes.

Authentication / ownership: `requireApexActor()` checks verified apex Host, fresh DB-backed session, account status, exact Origin, CSRF and Fetch Metadata for mutations. `MongoTenancyRepository` independently repeats session/account and ownership checks before every private DB operation. Owner IDs come from the validated session; server constructs every filter and project summary, never from the request body. No direct Mongo collections are imported by a route file.

Host resolver: the trusted edge can classify apex, www and one reviewed wildcard label. Real wildcard routing is off until production + explicit DNS/TLS flags. An untrusted `Host`, mismatch with `X-Forwarded-Host`, ambiguous encoding, deeper wildcard, invalid/reserved slug or any tenant-host request for login/API/dashboard/admin is denied. Direct internal `/_tenant` paths are denied. Correct routes are mapped to the same portfolio ID by `slugClaims`; public detail slugs are manifest-scoped to the **current active release**.

Live public gate: status `active`, existing `activeReleaseId`, owner account active, no current moderator suspension/quarantine/public deny, parsed immutable release from the exact active pointer, current security generation and current canonical slug claim. A second active-account/control read checks for revocation before output. `public` and `unlisted` both permit a direct released URL; unlisted excludes directory and noindex. `onboarding`, `owner_disabled`, `suspended`, `deleting`, missing/unreadable policy and disabled release **deny**. Never use a cached release or an old alias to bypass current policy. The public page remains a minimal safe placeholder until a validated compiler and media path exist.

SEO / indexing: All public routes currently send `noindex` and global robots deny all; Issue 14 will enable only eligible public releases after full semantic/SEO verification. Do not turn on page/edge static caching as a shortcut: immutable content may be cached only behind a live gate that runs for every public page, metadata, feed, AI, media or sitemap artifact.

No unaudited alternate policy writer: the pre-Issue-5 `MongoTenantRepository.comparePolicy` method is now fail-closed for owned rows, since it cannot supply a transaction and audit event. The supported `MongoTenancyRepository.changePolicy` handles CAS, ownership, moderation and audit in one transaction. Other product modules must not import infrastructure repositories directly through client or public renderer paths.

**Unverified:** Actual Next.js URL rewrite/encoded private folder, Mongo replica-set write conflicts/transaction semantics, Google/GitHub identity, physical TLS/edge X-Forwarded-Host trust, host-only cookies and browser/private CDN cache state. Tests using fake driver or simulated Host never substitute for these proofs.
